# RAPA

**Conheça seus ciclos. Viva com consciência.**

RAPA é uma plataforma de autoconhecimento baseada em ciclos, que integra conhecimentos ancestrais, registros pessoais e inteligência artificial para apoiar cada pessoa na compreensão da sua própria jornada.

Este repositório é tratado como um **produto de tecnologia em construção**, seguindo uma linha de **Product Company**: a documentação é parte do produto, escrita com o mesmo rigor de uma empresa de software madura.

---

## Mapa de Releases

```text
Foundation Release     (v1)  ← estamos aqui
 → Journey Release     (v2)
 → Community Release   (v3)
 → Knowledge Release   (v4)
 → Consciousness Platform (v5)
```

A **Foundation Release** valida a hipótese central:

> As pessoas desejam registrar sua jornada e compreender seus próprios padrões com a ajuda de IA e de sistemas simbólicos.

## Os quatro pilares do produto

1. **Conhecimento** — biblioteca, cursos, calendários, contexto das tradições.
2. **Experiência** — diário, sonhos, humor, hábitos, linha da vida.
3. **Consciência** — IA (KAI), análises de padrões, reflexões.
4. **Comunidade** — professores, grupos, eventos, compartilhamento opcional.

Na Foundation Release, os pilares aparecem como quatro verbos aplicados ao usuário: **Registrar · Conhecer · Refletir · Evoluir**.

## Ordem de construção — Redução de risco

Não seguimos a ordem tradicional de desenvolvimento. Seguimos a **ordem de redução de risco**.

- **Fase 0 — Fundação** ✅
  Brand Book · Product Discovery · Product Philosophy · Convenções.
- **Fase 1 — Entender o usuário** (em andamento)
  Personas · User Journey · Functional Specification (por sprints).
- **Fase 2 — Construir o hábito de retorno**
  Foundation Release: Registrar · Conhecer · Refletir · Evoluir.
- **Fase 3+ — Expansão**
  Journey, Community, Knowledge, Consciousness.
